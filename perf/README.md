# perf/ - S4 performance sprint workspace export

A text-only export of the multi-agent workspace used for the S4 performance
work on this branch (`perf/opt`): notes, harness and bench scripts, run
matrices, readouts, staged diffs and small results. It is generated by
`build/agent1/export/export_perf.py`.

Start with `notes/RESUME.md` (where things stand and what comes next; its top
block is the session 3 update), then `notes/SESSION3.md` (the final defaults,
confirmation windows and smoke tests), `notes/FINDINGS-AND-CHANGES.md` and
`notes/S4-DRAFT.md`.

| Folder | What it holds |
|---|---|
| `notes/` | `perf-notes/`: findings, the S4 draft, per-agent notes, session logs |
| `harness/` | the run-game harness: routes, virtual pad, stats scripts |
| `bench/` | benchmark scripts; `bench/agent5/launch` is the timed-window launcher, `bench/agent8/run` the matrix runner |
| `build/` | per-agent docs, readouts, handoffs, staged diffs and small records (`*-bin/MANIFEST.txt` describe the tested binaries) |
| `env/` | dev shell helpers |

Not included: game data, the recompiled game code (`rexlego/generated`),
disassembly, binaries, crash dumps, logs, raw per-frame data, and copies of
source files that are already in git.

Absolute paths were rewritten on export: `<workspace>` stands for the original
workspace folder (the one holding `DimensionsRecomp/`, `build/`, `bench/` and
`perf-notes/`) and `<user>` for the Windows account name. Scripts with
hard-coded paths need them set back before they will run.

`MANIFEST.tsv` lists every file with its source path, size and sha256.
