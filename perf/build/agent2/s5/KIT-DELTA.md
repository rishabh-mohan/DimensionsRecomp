## nops-smoke-run.ps1 (88C1ABBC7163B835 -> new sha after the lift)
- **S1, guards.**
  - New `Get-Refusals` function. It is checked at the start (as before) and **again before every arm**.
  - It covers: WINDOW-HOLD, **WINDOW-GO.txt**, the day launcher, a running game, Agent 8 runners, the hidden desktop, and **timed-window kit scripts**.
  - The script check is a Win32_Process scan, limited to powershell/pwsh/cmd/python/py, for a path separator plus `window-s5.ps1`, `RUN-WINDOW-S5*.cmd` or `run-matrix*.ps1|cmd|py` on the command line.
  - That narrows the any-command-line false refusals (D1): a grep that merely mentions a name doesn't match. The names appear only in the ps1 text, never on a command line.
- **S2, shot job.** It now takes `$runsRoot` and accepts only a legodimensions process with StartTime >= t0-2 s **and** Path under `<runsRoot>\`. So kit-shots can only be written inside our run dir. The dryrun self-test passes runsRoot too.
- **S3, cleanup and hold.**
  - The arm loop is wrapped in `try { } catch { } finally { Stop-Ours }`.
  - `Stop-Ours` (modelled on M16 rows-run.ps1):
    1. stops and removes our shot and hold jobs;
    2. if an arm is active, force-stops only a legodimensions.exe whose ExecutablePath is under runsRoot;
    3. stops only a child powershell of this PID running run-game.ps1.
  - New per-arm **hold watch** job. It polls WINDOW-HOLD.txt every 2 s. When the file appears, it sends WM_CLOSE (CloseMainWindow) to our game (image under runsRoot), then force-stops it if it is still there after 15 s.
  - After run-game returns, the kit stops on any hold-watch output: "STOP: WINDOW-HOLD.txt during arm X", no further arm.
  - The dryrun self-tests the hold watch with a scratch hold file. It expects "hold: WINDOW-HOLD.txt appeared; no game of ours running".
- **S4 / K6, bin re-check.** New `Check-Bin` runs after **every** arm: verify-bins plus MANIFEST == $pin. A FAIL means "STOP: bin check FAIL ... (results invalid, K6)". The last arm's check is the after-session check.
- The exit is 1 whenever the run stopped early (`$stop`), not only on arm rc, missing arms or post failure. `$stop` is shown in the DONE line.
- The header comment is updated.
